## Sobre o Projeto

Sistema de pedidos online desenvolvido para o **Supermercado Pedra Bonita**, um negócio familiar que busca modernizar seu atendimento. O objetivo é permitir que clientes façam pedidos de forma fácil e rápida, com os pedidos chegando diretamente no WhatsApp do estabelecimento.

### Sobre o Supermercado Pedra Bonita

O Supermercado Pedra Bonita é um estabelecimento familiar que preza pela qualidade no atendimento e proximidade com seus clientes. Este projeto nasce da necessidade de adaptar o negócio às novas tecnologias, mantendo o atendimento personalizado.

### Objetivos do Projeto

- **Modernizar** o processo de pedidos do supermercado
- **Facilitar** a vida dos clientes com pedidos online
- **Manter** a comunicação próxima via WhatsApp
- **Expandir** o alcance do negócio no ambiente digital
- **Criar** uma vitrine online dos produtos
